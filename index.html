COVER MAP

Every game is bound to one image file. Drop the files next to index.html with these exact names and they appear instantly — no code edit needed. Missing covers fall back to the built-in illustration, which prints the filename it expects.

1Recommended size 800×450 (16:9), JPG / PNG / WebP, under ~200 KB. Square or tall images get center-cropped automatically.
2Upload to the same folder as the page, or edit the cover value inside the ARCADE list at the top of the script to use another path (e.g. img/cover-cows.webp).
3The ＋ COVER button on each card lets you preview an image from your device right away. It is downscaled and kept in your browser only (localStorage) — perfect for testing before publishing. Use RESET PREVIEWS to clear it.
4Adding a brand-new game = copy one object in the ARCADE list, change id / file / title / desc / cover / accent / art. Everything else (card, filter, cover map, counters) builds itself.

ABOUT MINI GAMES ARCADE

Mini Games Arcade is an independent collection of free browser games. Our mission is simple: fun, bite-sized games you can play instantly — no downloads, no installs, no account required. Just open the site and press play, on your phone, tablet or computer.

Every game is hand-built, carefully tested and updated regularly. Your best scores, crystals and unlocked items are saved privately on your own device — we don't ask for personal data and we never will. New mini-games are added all the time, so keep an eye on the “Coming Soon” slot!

We are a small indie team making games with passion. If you have ideas, feedback or partnership requests, we would love to hear from you.
